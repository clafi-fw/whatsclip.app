Install guide

WhatsClip is a single program in an archive. Unpack it anywhere and run it - a folder in your documents, a tools folder, a USB stick.

Windows

Windows 10 or 11, 64-bit.

  1. Download WhatsClip-0.1.0-windows-x64.zip.
  2. Unpack it and run WhatsClip.exe.

The executable carries no code signature yet, so Windows may open it with Windows protected your PC. Choose More info, then Run anyway. To be sure the file is the one that was published, check the download first.

Linux

A Wayland session, glibc 2.35 or newer, and an x86-64 processor with AVX2 and FMA - every desktop distribution from spring 2022 on. Supported distributions lists the desktops and what each one offers.

tar -xzf WhatsClip-0.1.0-linux-x86_64.tar.gz
./WhatsClip/WhatsClip

When it does not start, the archive carries a checker that names what the machine is missing and how to install it:

./WhatsClip/clafi-check.sh ./WhatsClip/WhatsClip

Check the download

GitHub computes a SHA-256 checksum of every file when a release is published and shows it on the release page, next to the file. For version 0.1.0:

WhatsClip-0.1.0-windows-x64.zip on the release page WhatsClip-0.1.0-linux-x86_64.tar.gz on the release page

Compute the checksum of the file you downloaded, in the folder it was saved to, and compare the two.

Windows, in PowerShell 
Get-FileHash WhatsClip-0.1.0-windows-x64.zip
Linux 
sha256sum WhatsClip-0.1.0-linux-x86_64.tar.gz

Equal checksums mean your file is the one GitHub holds, byte for byte - PowerShell prints the letters in capitals, which changes nothing. The checksum belongs to the archive, so check it before you unpack.

Storing settings on this PC

WhatsClip starts with its defaults and writes nothing to your PC. Whatever you change lasts until it closes.

To keep your settings from one run to the next, open the application menu, go to Settings and tick Keep settings on this PC. WhatsClip names the folder it is about to create and asks first:

Windows%APPDATA%\ClaFi Framework\WhatsClip Linux~/.config/ClaFi Framework/WhatsClip, or under $XDG_CONFIG_HOME where it is set

Removing WhatsClip

Untick Keep settings on this PC first. WhatsClip asks, then deletes its settings folder. Then delete the folder you unpacked.

Sources

WhatsClip is open source under the zlib licence. It is one of the applications of the ClaFi framework, and its code is in the framework's repository, in Tools/WhatsClip. GitHub builds every release from that tree - the recipe is .github/workflows/release.yml.
