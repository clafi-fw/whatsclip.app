See what is on your clipboard.

WhatsClip shows the clipboard format by format and follows it as it changes. A format reads as a picture, as text in a chosen encoding, or as raw bytes.

Dark mode. WhatsClip comes in light and dark. It follows the system until you pick one in Settings.

Any scale. Scale the interface as you wish - text, icons and spacing grow together.

ClaFi themes. WhatsClip wears any ClaFi theme. Make your own in Themes.

Every format as text. Any format on the clipboard can be read as text, in the encoding you choose - HTML fragments, RTF, the private formats of other applications.

Syntax highlighting. Code copied from an editor is coloured. The language is detected, and you can pick another.

Exotic languages. However exotic the language is, its text is shaped and drawn the way it is written.

Code pages. When the text's code page is not detected, choose it from the list. Windows only.

Picture and text. Copy a picture together with its text and WhatsClip previews both - the picture and the text, a tab each.

Pixel by pixel. Zoom into a picture and point at a pixel to read its colour - as RGB hex, BGR hex, RGB decimal or CSS.

Alpha channel. Pictures with an alpha channel keep their transparency.
